# 多多卖菜 · 介绍短片文案（约 2 分钟）

口播约 **500 字**，正常语速大约 **1 分 50 秒～2 分 10 秒**。别念太满，段与段之间留半拍，画面切一下也更自然。
语气按跟朋友安利模组来：轻松、口语，不要念说明书。

## 分镜口播（带画面建议）

### 1. 开场｜0:00–0:15

**画面：** 家园农田、箱子堆满作物；可以扫一眼塞不下的小麦/土豆。

**口播：**
你有没有过这种时候：田种好了，箱子堆满了，作物一箱一箱的，吃不完也用不完。

### 2. 引入｜0:15–0:28

**画面：** 切到网店界面（按 H 打开），四个页签扫一眼。

**口播：**
那就开个小网店吧。多多卖菜，就是干这个的。默认按 H，家里就能买卖。

### 3. 卖货｜0:28–0:58

**画面：** 货源指南针对箱子右键 → 我的店铺上架（数量、单价、建议价）→ 挂单列表；可带一句店铺升级进度。

**口播：**
想卖东西，拿货源指南针对着箱子右键一标，货就算进店了。到「我的店铺」挑货、填数量、填单价，旁边有今天的建议价。便宜卖得快，贵了就得等；标太高一直挂着也没人买，随时能下架。卖得越多店铺越升级，挂单从十格涨到六十格。

### 4. 商城｜0:58–1:22

**画面：** 商城首页滑动；切农产/矿石/食品/建材/花店；热销、促销角标；购物车结算；点进详情看评价。

**口播：**
买东西去商城。农产、矿石、食品、建材、花店，好几家店随便逛，能搜能筛，每天货架还会打乱，热销促销都有角标。看中了丢购物车一起结，也可以当场买。详情里还有买家评价，口吻跟随手写的一样。

### 5. 余额和快递｜1:22–1:48

**画面：** 点余额看账单 → 物流页（在途、快递公司）→ 收货点 → 快递盒像沙子一样落下叠放 → 右键拆开拿货。

**口播：**
钱走账户余额，点一下就能翻账单。下完单包裹在路上，快递有快有慢，有的还挺「放门口」那种感觉。家里放个收货点设成默认——到了快递盒会像沙子一样往下落，一盒叠一盒，右键拆开就能拿货。

### 6. 收尾｜1:48–2:05

**画面：** 市价/货架一晃而过；可闪一下农夫乐事等联动物品；最后定在网店主界面或家园收货点。

**口播：**
市价会跟着你的买卖晃。原版农矿食杂都能走；装了农夫乐事、妖怪的归家这些，对应物品也会自己进目录。

箱子里堆不下的拿去挂，缺的上网买，快递送到家门口。轻量家园经营，不搞复杂。多多卖菜，按 H 开店就行。

## 剪辑备忘

- 开场别急着出 UI，先给农田和满箱，观众才知道「这模组解决啥」。
- 「按 H」出现时，最好有按键提示或手按下去的镜头。
- 快递盒下落是记忆点，给足 3～5 秒，别一闪而过。
- 结尾那句「按 H 开店就行」可以叠模组名 / 版本：Minecraft 1.20.1 · Forge。
- 如果要压到刚好 2 分钟：收尾「市价会跟着你的买卖晃」那句可删，直接接最后一段。
